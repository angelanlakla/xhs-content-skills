# 小红书爆款拆解与原创改写 Skill

这是一个用于小红书内容分析与原创写作的 Agent Skill。它可以拆解爆款笔记、分析评论区、优化二创脚本，并在保留传播机制的基础上生成原创内容。

## 功能

- 拆解标题钩子、正文结构和用户心理
- 分析点赞、收藏、评论等互动数据
- 总结评论区整体情况和用户需求
- 提取高赞评论并派生新选题
- 使用 dbs-content 方法诊断选题的内容形式和创作方向
- 对比参考爆款与目标脚本
- 优化标题、开头、结构、节奏和结尾互动
- 基于爆款机制生成原创小红书图文或视频口播稿
- 检查虚假数据、AI 味、洗稿和平台风险

## 目录结构

```text
xhs-analyze-and-rewrite/
├── SKILL.md
└── references/
    └── account-profile.md  # 可选：账号定位与表达风格
```

`SKILL.md` 是必须文件。`references/account-profile.md` 用于保存账号定位、目标用户、内容方向和个人表达习惯。

## 安装

### Codex

将 `xhs-analyze-and-rewrite` 文件夹放到：

```text
~/.codex/skills/
```

最终路径应为：

```text
~/.codex/skills/xhs-analyze-and-rewrite/SKILL.md
```

### 其他 Agent

如果使用的 Agent 支持 `SKILL.md`，将整个文件夹放入对应的 Skills 目录。不同平台的安装位置可能不同。

## 使用示例

### 爆款拆解

```text
请使用 xhs-analyze-and-rewrite 拆解这篇小红书笔记，分析标题、正文结构、用户心理和爆款原因。
```

### 评论分析

```text
请总结这篇笔记的评论区，找出高赞评论、主要问题、用户需求和可以继续做的选题。
```

### 脚本优化

```text
这是参考爆款和我的目标脚本。请对比钩子、结构、证据、节奏和结尾，并输出修改后的完整脚本。
```

### 原创改写

```text
请学习这些参考笔记的选题和传播结构，结合我的账号定位生成一篇原创笔记。不要复制原句、案例和作者经历。
```

## 输入建议

为了获得更可靠的结果，尽量提供：

- 笔记标题和正文
- 原笔记链接
- 图文或视频类型
- 发布时间
- 点赞、收藏、评论和分享数据
- 作者粉丝数
- 评论内容及评论点赞数
- 需要优化的脚本
- 账号定位、目标用户和真实经历

缺少部分数据时仍可分析，但 Skill 会标注信息限制，不会编造缺失数据。

## 输出模式

Skill 支持四种模式：

| 模式 | 用途 |
|---|---|
| `note-analysis` | 爆款笔记拆解 |
| `comment-analysis` | 评论区与用户需求分析 |
| `content-diagnosis` | 选题通过后的内容形式与五维诊断 |
| `original-rewrite` | 基于传播机制生成原创稿 |
| `script-review` | 目标脚本对标和优化 |

用户只要求分析时，Skill 不会自动生成仿写稿。

## 与 dbs-content 配合

如果本机安装了 `dbs-content`，本 Skill 会在选题确定后调用它完成内容创作诊断，再进入原创写作：

```text
爆款与评论分析
        ↓
确定一个选题方向
        ↓
dbs-content 内容诊断
        ↓
original-rewrite 原创写作
        ↓
script-review 成稿检查
```

`dbs-content` 只负责判断内容应该怎么做，不负责代写。若未安装它，本 Skill 会使用内置的形式匹配和五维诊断作为降级方案。

五维诊断包括：

- 文字质量
- 封面标题
- 表达效率
- 认知落差
- 内容目标与承接路径

## 原创与事实原则

- 不逐句同义替换
- 不复制原作者的个人经历
- 不伪造收益、粉丝增长或使用效果
- 不冒充亲测
- 不虚构用户占比、停留时间和转化率
- 区分事实、合理推断和未知信息
- 学习传播机制，不复制独特表达

## 账号定位文件

可以在 `references/account-profile.md` 中记录：

```markdown
# 账号定位

## 目标用户

文科背景、希望学习和使用 AI 的普通人。

## 内容方向

- 文科生 AI 入门
- AI 工具和工作流
- 普通人的 AI 提效与变现实践

## 表达风格

- 真实
- 直接
- 少术语
- 强调可执行步骤

## 禁止事项

- 不编造个人经历
- 不夸大收益
- 不逐句洗稿
```
